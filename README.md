## ⚡ Overview

Designed to showcase leadership, impact ventures, and strategic initiatives, this platform combines elegant modern aesthetics with interactive intelligence:
* **Interactive AI Chatbot Companion (`AIChatbot.tsx`):** Allows visitors and investors to query background, venture philosophies, and career milestones through natural conversation.
* **Chronological Impact Timeline (`Timeline.tsx`):** Interactive visualization tracing milestone accomplishments, speaking engagements, and institutional advisory roles.
* **Venture Portfolio & Vision Showcase (`Ventures.tsx`, `Vision.tsx`):** Deep dives into incubated projects, social impact initiatives, and long-term theses.

## 🛠️ Tech Stack

- **Framework:** React 18, TypeScript, Vite
- **AI Integration:** Embedded Contextual Chat Engine (`AIChatbot.tsx`)
- **Styling & UI:** Tailwind CSS, Radix UI Primitives, Lucide Icons, Sonner notifications

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/mdroushanalam-astra/ariba-irfan-architect-of-impact.git
cd ariba-irfan-architect-of-impact

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
